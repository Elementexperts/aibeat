<h2>What happened</h2>
<p>Block released a new voice model called Dessa.</p>
<p>Dessa is a full‑duplex speech‑to‑speech model that can talk and listen at the same time and can express emotions such as laughs, pauses, cries, and sounding tired when appropriate.</p>
<p>The model can run locally on consumer GPUs such as a MacBook M4 Max or better.</p>
<p>Dessa was trained entirely on human speech using a single NVIDIA GPU rack.</p>
<p>The model is not publicly accessible yet, and Block has invited safety researchers to test it.</p>
