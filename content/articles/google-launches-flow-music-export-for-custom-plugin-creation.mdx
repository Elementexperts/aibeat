<h2>What happened</h2>
<p>Google announced that producers can export custom Spaces as VST3/AU plugins to run inside digital audio workstations, a feature added to Flow Music’s Spaces functionality, and producer Khris Riddick‑Tynes demonstrated it with a plugin named No Chaser.</p>
<p>The export capability lets creators build custom instruments or effects using natural language without needing coding experience.</p>

<h2>AIBeat analysis</h2>
<p>This could let musicians without programming skills create and share plug‑ins directly from Flow Music, potentially expanding the pool of available DAW tools and simplifying workflow integration.</p>
