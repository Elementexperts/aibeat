<h2>What happened</h2>
<p>Anthropic announced the launch of Claude Ship, a suite of AI agents designed to automate code reviews, fixes and approvals of routine code changes.</p>
<p>The suite includes three agents: Code Review, which is generally available; PR Steward, currently in beta and focused on failing CI checks, merge conflicts and feedback from Code Review; and Claude Approvals, also in beta, which applies approval policies written as repository files and can incorporate signals such as Code Review findings or classifiers, with policies expressed in natural language.</p>
<p>Claude Ship is being rolled out to Claude Team and Enterprise plans for repositories hosted on GitHub, with Code Review already generally available while PR Steward and Claude Approvals remain in beta.</p>
<p>Anthropic retains control over where Claude Ship runs, the review settings (Quick, Standard, Deep) and which changes are escalated to a human reviewer.</p>
<p>Teams using Claude Ship can set monthly spending limits and begin with a single repository to manage costs and scope.</p>
<p>Because the approval functionality is still in beta, Anthropic suggests running it in observe‑only mode first to evaluate its behavior before enabling automatic approvals.</p>

<h2>AIBeat analysis</h2>
<p>This could allow development teams to automate routine review tasks, freeing engineers to concentrate on more complex work; the ability to set spending limits and start with one repository offers a low‑risk entry point, while the recommendation to use observe‑only mode signals that Anthropic is cautious about reliability, suggesting teams should monitor outcomes before fully delegating approvals to the AI agents.</p>
